# Hardware

KiCad schematic/PCB, BOMs, and hardware notes for the ultra-low-power alarm clock.

| Path | Purpose |
| --- | --- |
| `kicad/` | Schematic, PCB, libraries, fab exports |
| `bom/` | Production and prototyping BOMs |
| `docs/` | Pin maps, energy budget, EMC notes |

Architecture choices (MCU, display, DCF-77, LIS3DH, power) live in the repo-root [`AGENTS.md`](../AGENTS.md).
