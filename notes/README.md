# Evidence log

Loose notes for the thesis. Promotor rule: write them while the prototype is built. Chapters come later.

## Layout

| Path | What |
| --- | --- |
| `deadlines.md` | Faculty, promotor, and draft dates |
| `log/` | One file per session or milestone |
| `media/` | Screenshots, photos, analyzer captures |
| `measurements/` | CSV plus the conditions of the run |
| `ai-use.md` | Every kept AI output |
| `sources.md` | Pointer to the bibliography |
| `TEMPLATE.md` | Copy this for a new note |

## Name files

`YYYY-MM-DD_topic_detail.ext`

Example: `2026-10-06_dcf_generator_pulse_timing.png`

## What a note must say

Date. What was done. What failed. How it was fixed. Why a part or library was chosen.

Console output goes in as text. Screenshots use a light theme. Measurements are CSV with instrument, temperature, supply, and firmware commit.
